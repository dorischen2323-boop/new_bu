## 1. 設計主張

**版型說「我有品味、我是顧問」，數字說「我是硬的、我看數據」。**

版型走雜誌編輯部風格（大留白、宋體大標、單欄敘事），
但每次講到成果就切換成儀表板語言（等寬字、大數字、KPI 卡）。

理由：Doris 的差異化不是「15 年數位行銷」，而是
**「懂行銷、而且自己動手做得出 AI 工作流」** —— 這個組合市場上極少，
需要同時傳達「顧問的品味」與「操盤手的硬度」。

## 2. 配色：灰粉柔紗 × 深潮藍（方案 D，定案）

靈感來源：
- 主體 —— 使用者提供之「灰粉柔紗」參考圖（蜜桃粉 `#F2C9CB` × 淺炭灰 `#B6BAC0` 漸層 + 顆粒噪點）
- 第二主色 —— 取自「泳池派對」配色的 Pool Bottom `#227E9D`，壓深為 `#1B6C88`

### 2.1 雙主色分工（本設計的核心）

一個顏色講不完「行銷操盤手 ＋ 會寫系統的人」，所以用兩色分擔：

| 色 | 語意 | 用在哪 |
|---|---|---|
| `#8F4A53` **深玫瑰** | **行銷側** — 成果、業績、人 | KPI 數字、CTA、案例成果、行銷技能標籤 |
| `#1B6C88` **深潮藍** | **技術側** — 系統、數據、AI | 技術標籤、AI 工作流案例、圖表主序列 |

### 2.2 角色分配（重要）

| 色 | 角色 | 禁止 |
|---|---|---|
| `#F2C9CB` 蜜桃粉 | 背景漸層、行銷類數據卡底染 | **永不承載文字**（白底對比僅 1.3:1） |
| `#B6BAC0` 淺炭灰 | 分隔線、標籤底、圖表次要序列 | 不當主文字色 |
| `#96D0D2` 淺潮藍 | 技術類數據卡底染、圖表淺序列 | **永不承載文字** |
| `#8F4A53` 深玫瑰 | 主色（行銷） | — |
| `#1B6C88` 深潮藍 | 第二主色（技術） | — |

> **為什麼要壓深？**
> 蜜桃粉在白底對比 1.3:1、原色 Pool Bottom `#227E9D` 對比 4.43:1（小字踩線）。
> 深玫瑰 6.2:1 ✓、深潮藍 5.67:1 ✓、白字置於深潮藍上 5.92:1 ✓ —— 全數通過 WCAG AA。

### 2.5 柔紗漸層 + 顆粒

參考圖最迷人的不是顏色，是**那層噪點** —— 它讓漸層有紙感、不呆板。

```css
Hero 背景 = linear-gradient(135deg, #F2C9CB 0%, #DFD8DE 44%, #9FB8C4 100%)
          + SVG feTurbulence 噪點 @ opacity .07
          + 底部往 --bg 淡出（文字落在淡出區才讀得清楚）
```

> 漸層右端由原本的 `#B6BAC0` 改為帶藍的 `#9FB8C4`，
> 讓深潮藍在首屏就先出現一次，後面章節再出現才不突兀。

噪點用 inline SVG data URI（約 2KB，不需外部圖檔）。

**使用位置**：Hero 背景、區塊分隔帶、案例卡縮圖。

- 行銷類縮圖漸層：`140deg, #F2C9CB → #DED5DA → #B6BAC0`
- 技術類縮圖漸層：`140deg, #96D0D2 → #C3CFD8 → #1B6C88`

## 4. 版面

- 最大容器 **1120px**
- 正文欄寬 **680px** — 一行 30–36 個中文字，繁中閱讀最舒服
- 垂直節奏 8px 基準；區塊間距 **104px**（手機 72px）
- 圓角：卡片 14px、標籤 999px、小元件 8px
- 陰影極輕：`0 1px 2px rgba(38,40,44,.04), 0 8px 24px -12px rgba(38,40,44,.10)`
- 手機優先單欄，≥768px 才出現多欄

## 5. 動態（刻意克制）

顧問網站的可信度來自克制，**不做視差、不做游標特效**。

| 效果 | 規格 | 使用範圍 |
|---|---|---|
| 進場 | `fade-up 24px / 320ms / ease-out` | 各區塊 |
| 數字 count-up | 900ms `easeOutCubic`，`IntersectionObserver` 觸發一次 | **只在首頁 KPI 條用一次** |
| 卡片 hover | `translateY(-3px)` + 陰影加深，220ms | 案例卡 |
| 按鈕 hover | 背景加深 + `translateY(-1px)`，180ms | |

⚠️ 需支援 `prefers-reduced-motion: reduce` → 全部關閉。

## 6. 沒有個人照的視覺策略

**結論：不放圖庫人像照。** 圖庫人像放在個人網站上是最快摧毀信任的東西，看的人一眼就知道不是本人。

改用三件套：

1. **排版本身當視覺** — Hero 不放照片，放一句超大宋體壓在柔紗漸層上
2. **數據圖表當主視覺** — 脫敏後的 Dashboard 截圖、CPA 下降曲線、月成長柱狀圖，統一套灰粉色調
3. **抽象色塊當節奏** — 區塊之間插柔紗漸層帶，代替圖片的呼吸感

### 之後若要補照片（優先順序）

1. 自己手機拍的工作情境照（不入鏡臉也行：桌面、螢幕、手寫筆記）→ 套灰粉調色
2. 朋友幫拍半身，自然光、素色背景
3. 圖庫**物件照**（不含人）

**圖庫關鍵字**：`minimal desk flatlay muted`、`soft pink grey gradient abstract`、
`notebook workspace neutral tone`、`blurred bokeh dusty rose`
**來源**：Unsplash / Pexels（免費可商用），只挑冷調偏灰的，回來統一套色。

## 7. 文案語氣規範（重要 — 在職中）

Doris 目前仍任職水球軟體學院，**全站不得出現「接案」相關措辭**。

| ❌ 不寫 | ✅ 改寫 |
|---|---|
| 接案 / 接單 | 顧問合作 |
| 報價 | 合作方式 |
| 承接專案 | 一起看看能做什麼 |
| Hire me | 聊聊 |

`/services` 頁面標題改為 **「合作方式」**，
語氣從「我在賣服務」轉成「我在說明我怎麼幫人解問題」。

### 案例去識別化寫法

```
❌ MG 汽車 2023 年潛客名單專案
✅ 某汽車品牌｜潛客名單成本優化
   協助單月獲取 10,000+ 潛在名單，CPA 壓在 3,000 元以下
```

**數字全留、品牌變類別。**
品牌名字只出現在「服務過的品牌」文字牆，**不與個別案例做連結**。

使用者決定：**放名字、不放 logo**。

```
MG 汽車 · 日立冷氣 · 客委會 · 和泰汽車 · 光泉 · SONY 影業 · 中華汽車
統一 · 淘寶網 · 天貓 · 遠傳 · 大同電子 · 梅花錶 · 時間寵愛 · 悠美醫美
```

字體 Noto Serif TC 400，行高 2.1，品牌名 600 加深，間隔符號用 `--slate` 色。
