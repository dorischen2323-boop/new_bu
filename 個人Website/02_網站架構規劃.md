## 5. 技術架構

沿用 Doris 已在跑的棧（零學習成本）：

| 層 | 選型 | 理由 |
|---|---|---|
| 框架 | **Next.js 15 App Router，`output: "export"`** | 已熟悉，靜態匯出無伺服器成本 |
| 樣式 | **Tailwind CSS v4** | 同上 |
| 內容 | `content/*.ts` 型別化資料檔（第一期） | 改文字＝改一個檔，不碰版型 |
| 部署 | **Cloudflare Workers**（`wrangler deploy`） | 同 AI×BDD Demo 站流程，免費且快 |
| 網域 | **doris.works** | 建議在 Cloudflare Registrar 註冊（約 USD $25/年），DNS 一鍵綁定 |
| 分析 | GA4 + Cloudflare Web Analytics | |
| 第二期 | **Supabase** | 聯絡表單收名單、文章、瀏覽統計；直接複製現成 anon key + RLS 模式 |
