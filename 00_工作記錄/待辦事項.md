## ⚠️ 環境注意
- **Bash 工具的 `date` 與 Windows 本機時間差 4 小時**。工作記錄的 `## HH:MM` 時間戳一律用 PowerShell `Get-Date` 取得，不要用 Bash `date`（來源：2026-07-30）
- **Bash 與 PowerShell 語法不可混用**。多行 commit message 在 Bash 裡要用 heredoc（`git commit -F - <<'EOF'`），PowerShell 的 here-string `@'...'@` 在 Bash 會壞掉（來源：2026-07-30）
- **中文路徑下 `wrangler deploy` 會 exit 127**。所以 `personal-site\` 刻意放純英文路徑，不要把它搬進含中文的資料夾（來源：2026-08-19）
- **Bash heredoc 傳中文路徑時，`\00` 之類的序列會被吃成控制字元**。寫含 Windows 路徑的中文內容時改用 Write 工具，不要用 Bash heredoc + Python（來源：2026-08-19）
