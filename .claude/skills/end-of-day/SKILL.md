# 收工 — 00-NB 工作區收尾流程

> 適用工作區：`C:\Doris\00-NB`
> 規則來源：`C:\Doris\00-NB\CLAUDE.md`
> **全程使用繁體中文。**

## 觸發時機

- 「收工」
- 「今天到這」「今天先這樣」「今天就這樣」
- 「下班了」「結束今天」「今天結束」

## 步驟 2：補完當日工作記錄

### 2.1 檢查當日檔案

- 路徑：`C:\Doris\00-NB\00_工作記錄\工作記錄_YYYYMMDD.md`
- 存在 → 讀出來，看今天已記錄到哪，**append** 尚未記錄的部分（**絕不覆寫既有內容**）
- 不存在 → 依 `CLAUDE.md` 第 2 節模板新建

### 2.2 回顧今天做了什麼

從以下來源蒐集，不要憑印象亂寫：
1. 本次對話從頭到現在做過的事
2. `git status` + `git log --oneline --since=midnight`（若是 git repo）
3. 今天有異動的檔案：`git diff --name-status`（未 commit 的部分）

### 2.3 寫入內容

每段工作一個 `## HH:MM — 主題` 小節，內含：
- **做了什麼**：具體完成項，一項一行
- **產出／異動檔案**：`路徑` — 改了什麼
- **決策與原因**：有取捨的地方記下為什麼（未來的自己會需要）
- **未完成／下一步**：`- [ ]` checkbox 格式

---

## 步驟 3：彙整未辦完事項 → 待辦清單

### 3.1 掃描來源（全部都要看）

1. 今天工作記錄裡所有未勾的 `- [ ]`
2. 本次對話中出現但沒做完的事（使用者提過、被中斷的、說「之後再說」的）
3. `00_工作記錄\待辦事項.md` 既有的未完成項目（延續，不要弄丟）
4. 程式碼中今天新增的 `TODO:` / `FIXME:` 註解（若有動到程式碼）

### 3.2 寫入 `00_工作記錄\待辦事項.md`

這是**滾動更新的總清單**，格式：

```markdown
# 待辦事項

> 最後更新：YYYY-MM-DD

## 🔥 優先處理
- [ ] <事項> — <為什麼卡住／下一步是什麼>（來源：YYYY-MM-DD）

## 📋 一般待辦
- [ ] <事項>（來源：YYYY-MM-DD）

## ❓ 待確認
- [ ] <需要問人或等回覆的事>（來源：YYYY-MM-DD）

## ✅ 已完成（近期）
- [x] <事項>（完成於 YYYY-MM-DD）
```

規則：
- **既有未完成項目一律保留**，不要因為今天沒碰到就刪掉。
- 今天完成的項目從待辦區移到「已完成（近期）」並標日期。
- 「已完成」區只留最近 14 天，更早的直接刪（歷史在當日工作記錄裡查得到）。
- 每項都要寫得夠具體，明天看得懂「下一步要做什麼」。

### 3.3 同步到當日工作記錄

在當日 `工作記錄_YYYYMMDD.md` 檔尾附上：

```markdown
## 📌 明日待辦
- [ ] <從待辦清單挑出明天要做的>
```

## 步驟 5：詢問是否 commit + push

**先確認 remote 是個人帳號**（依 `CLAUDE.md` 第 4 節鐵則）：

```bash
git -C C:\Doris\00-NB remote -v            # 應為 github.com/dorischen2323-boop/...
git -C C:\Doris\00-NB config user.email    # 應為 doris.chen2323@gmail.com
```

- 若 remote 指向 `Waterball-Software-Academy` 或 `Doris2323`，或 user.email 不是 `doris.chen2323@gmail.com` → **停下來警告使用者**，不要 push。
- ⚠️ 不可用 `gh repo create`／`gh` 相關指令代push：`gh` CLI 登入的是 `Doris2323`，不是本 repo 的帳號。
- 若尚未設 remote → 只提議 commit，並提醒「還沒設 remote，要 push 需先建個人帳號的 repo」。

確認無誤後問：

```
要把今天的工作記錄 commit 並 push 嗎？
- A) commit + push
- B) 只 commit，不 push
- C) 都不要，我自己處理
```

- commit message 格式：`docs: 工作記錄 YYYYMMDD`
- **絕不**在未得到明確同意前 commit 或 push。

## 注意事項

- **全程繁體中文**，不可切換語言。
- **絕不覆寫**既有的工作記錄或待辦清單內容，一律 append／合併。
- **絕不**碰 `WSA\` 底下的任何東西（已在 `.gitignore`，也不要手動 add）。
- 禁止任何會讓本機檔案消失的 git 操作（`reset --hard`、`stash -u`、切到沒這些檔案的分支）。
- 若今天其實沒做什麼事，仍要建立當日記錄（寫「今日無實質工作異動」），並照樣更新待辦清單的「最後更新」日期。
